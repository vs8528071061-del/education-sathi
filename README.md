## 🌟 Overview

**Education Sathi** is a full-stack, mobile-first web application designed for students and parents navigating higher education admissions across India. It specializes in medical programs (**MBBS, BAMS, BHMS, BUMS, MD/MS**), all 36 Indian States & Union Territories, central/state scholarships (including MP MMVY), and real-time AI career advisory.

---

## 🚀 Key Features

- **🗺️ Pan-India 36 States & UTs Hub**: Direct college directories, state quota rules, and verified fee matrices across all Indian states.
- **🩺 Dedicated Medical Course Directory**: Complete roadmaps for MBBS, BAMS, BHMS, BUMS, and MD/MS with duration, NEET eligibility, cutoffs, seat matrices, and 3-tier fee breakdowns (Government vs. Private vs. Deemed).
- **🤖 Ask Education Sathi AI**: Intelligent admission assistant calculating admission probabilities, quota eligibility, and choice-filling sequencing.
- **🏆 Scholarship Discovery Engine**: Accurate eligibility calculator for MP MMVY (100% Tuition Fee Waiver), NSP Central Schemes, and Post-Matric schemes.
- **📊 Interactive NEET College Predictor**: Real-time likelihood calculator based on previous year closing ranks and categories (General, OBC, SC, ST, EWS).
- **⚖️ Side-by-Side College Comparator**: Direct comparison of fees, hospital beds, NIRF rankings, and annual cutoff scores.
- **🔐 Admin CRM Dashboard**: Real session-authenticated CRM (`admin` / `educationsathi2026`) for managing student counselling leads, exporting CSVs, and tracking inquiry statuses.
- **📱 Responsive Mobile Experience**: Native app aesthetic with sticky bottom navigation, touch-friendly filter bars, and quick WhatsApp/Call floating actions.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, Responsive Grid/Flexbox), JavaScript (ES6+ Single Page Application Architecture)
- **Icons & Typography**: FontAwesome 6 Pro, Google Fonts (*Outfit* & *Plus Jakarta Sans*)
- **Backend**: Node.js, Express.js REST API
- **Data & Persistence**: File-backed database with automated data seeding (`server/db.js`)

## 💻 Local Installation & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/education-sathi.git
cd education-sathi
```

### 2. Install Server Dependencies
```bash
cd server
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 4. Start the Application
```bash
node server.js
```

Open your browser and navigate to:
👉 **[http://localhost:5000](http://localhost:5000)**
